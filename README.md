# RTI
Using Oakley's 2004 paper on RTI, I created an ODE/PDE solver to observe the perturbation growth rate using different parameters. 
## Overview
When observing from an undisturbed state which is essentially equilibrium where one fluid perfectly lies on top of the other. If there is even a small displacement, you would see the heavier fluid sink, while the lighter fluid rises.
This growth further develops until we get the formation of rising columns of light fluid known as bubbles, and falling columns of the heavier fluid known as spikes. 
## Tools Used
- An academic paper deriving the system of ODEs from the Navier-Stokes equations
- Python, including libraries such as NumPy, SciPy, and matplotlib for analysis
- Claude for debugging ODE/PDE solver
- Linear Stability Analysis
